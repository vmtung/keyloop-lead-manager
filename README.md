# Lead Manager

A Sales Lead Management Tool for dealership salespeople (Keyloop technical assessment, Scenario C,
Demand domain). Work in progress.

## Requirements

- Node 24 (see `.nvmrc`)
- pnpm 11

## Build, run, test

```bash
pnpm install
pnpm dev         # http://localhost:5173
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```
